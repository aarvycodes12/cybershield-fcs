# CyberShield Attack Simulation & Detection Lab

A static, browser-based educational demonstration of common security detection scenarios.

## Features
- Brute-force login pattern simulation
- SQL injection-shaped input detection demonstration
- XSS-shaped input detection demonstration
- Normal traffic baseline
- Live event feed and event log
- CSV export

## Deploy with GitHub Pages
1. Create a new public repository on GitHub, e.g. `cybershield-demo`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a minute or two and open the published Pages URL shown in Settings → Pages.

## Important scope note
This is a browser-only simulation. It does not send network traffic, attack a server, connect to a database, or provide production-grade security detection. All displayed events are generated locally for teaching and presentation purposes. Describe it as a simulated detection prototype in your report.
